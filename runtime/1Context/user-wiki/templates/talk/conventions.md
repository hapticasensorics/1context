# Talk Conventions

Talk pages are append-oriented discussion records for improving wiki pages. Use
new entries for proposals, replies, corrections, and closures.

Use this file only when a page explicitly selects `talk/conventions.md`.
Current e08 templates live under `templates/talk/conventions/`:

- `for-you.md`
- `your-context.md`
- `projects.md`
- `topics.md`
